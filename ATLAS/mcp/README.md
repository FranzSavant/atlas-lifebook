# MCP

> Pi no trae MCP nativo (filosofía: CLI + README). Si lo necesitas, crea una extensión en `.pi/extensions/mcp-bridge/` que registre el MCP.

Ver `docs/custom-provider.md` y `examples/extensions/` en pi.
